# Better Mods Menu 2.4

Улучшенное ванильное меню модов для The Binding of Isaac: Repentance+. Нужен **REPENTOGON**.

Это не отдельное окно, а то же меню модов: та же бумага, курсор, записки «PRESS TAB» и
«PRESS ⟵ TO UNDO», нарисованные спрайтами самой игры. Поверх них добавлены нужные функции.

## Что умеет

- Лист и стена неподвижны, список плавно прокручивается под шапкой.
- Метка категории (API / CONTENT / QOL / VISUAL), `+`/`-` у модов, которые
  изменятся после перезапуска, `⚠`, если включённому моду не хватает зависимости.
- Карточка мода: название, версия, Workshop ID, теги, превью, статус и описание.
- Звуки самой игры: включение/выключение мода и галочек в настройках — щелчок светлой/тёмной
  стороны из выбора персонажа (`MENU_FLIP_LIGHT/DARK`), фильтры и значения влево/вправо —
  стрелки выбора персонажа (`CHARACTER_SELECT_LEFT/RIGHT`), курсор — родной `MENU_SCROLL`,
но громче (в игре он примерно в 10 раз тише остальных и тонет в музыке меню).
Ванильное переключение мода беззвучно.
- Строка мода: крупная обложка слева, название, справа шестерня (есть настройки) и категория.
  Выключенный мод — бледное название и приглушённая обложка, галочек нет.
- Весь текст набран шрифтом меню самой игры (`teammeatex`), мелкий — им же в уменьшенном
  масштабе: маленький шрифт HUD (`pftempestasevencondensed`) имеет тёмную обводку и на бумаге
  расплывается.
- Иконки из Steam Workshop рядом с названиями и в карточке; локальные превью используются
  как запасной вариант. Загруженные обложки работают без интернета.
- Зависимости определяются по описанию мода (ссылки на Workshop и названия рядом со словами
  «requires», «depends on»…). **D** включает все недостающие.
- Фильтры: все, вкл, выкл, закреплённые, API, контент, QoL, визуал, изменённые, сломанные.
- Сортировка: по имени, сначала включённые, по категории.
- Закреплённые моды всегда наверху.
- Профили: 4 слота, плюс «как при запуске игры» и «всё выключить».
- Настройки других модов из Mod Config Menu и Dead Sea Scrolls прямо на листе меню.
- Поиск (CTRL) и откат (BACKSPACE) от REPENTOGON работают как раньше.

## Управление

| Клавиша | Действие |
|---|---|
| ↑ ↓, колесо мыши | выбор мода |
| PgUp / PgDn, Z / X, Home / End | листать |
| ← → или Q / E | фильтр |
| ENTER / SPACE | включить/выключить мод |
| S | сортировка |
| B | закрепить мод |
| D | включить недостающие зависимости |
| [ ] | прокрутить описание |
| P | профили (ENTER применить, S сохранить в слот, C очистить, SHIFT+1..4 быстро сохранить) |
| O | настройки выбранного мода, у модов без настроек открывается общий список |
| CTRL | поиск (печатать, ENTER закончить) |
| BACKSPACE | отменить все изменения с момента запуска игры |
| TAB | выключить/включить все моды (ванильная функция) |
| F2 | вернуть обычное ванильное меню (и обратно) |
| L | язык интерфейса: русский / English (по умолчанию — как в настройках игры) |
| ESC | выйти |

Геймпад: крестовина, A — включить мод, LB/RB — фильтр, LT/RT — листать, Y — панели.
В панелях LB/RB переключают профили и настройки, B закрывает. В профилях Y сохраняет текущий
набор в выбранный слот. Если клавиатурная привязка ждёт клавишу, B отменяет ожидание.
Проверено 2026-11-22 в игре: действия геймпада подставлялись тестовым модом от имени
контроллера №1. Настоящий геймпад не подключали.

## Как это устроено

Lua не может сам включать моды. Поэтому мод перехватывает ввод меню (`MenuManager.SetInputMask`),
рисует свой список и ставит ванильный курсор (`ModsMenu.SetSelectedElement`) на выбранный мод.
Нажатие ENTER доходит до игры, и REPENTOGON переключает мод и пишет `disable.it` как обычно.
Профиль применяется так же: курсор сам переходит к каждому моду, который нужно изменить, и
на каждый нужно нажать ENTER.

`bmm/repsearch.lua` покадрово повторяет логику поиска и отката REPENTOGON
([`ModsMenuStuff.cpp`](https://github.com/TeamREPENTOGON/REPENTOGON/blob/main/repentogon/Patches/ModsMenuStuff.cpp)):
клавиатуру он читает напрямую, и без этого порядок списка разошёлся бы.

Если в коде мода что-то упадёт, он снимает маску ввода и до конца сессии показывает ванильное
меню, так что застрять в меню нельзя. Ошибка пишется в `log.txt` с префиксом `[BetterModsMenu]`.

## Настройки других модов

Шестерёнка в списке значит, что у мода есть настройки. `bmm/config.lua` читает глобальные
таблицы `ModConfigMenu.MenuData` и `DeadSeaScrollsMenu.Menus` и превращает их в страницы,
которые рисует `bmm/ui.lua`. Сами меню MCM и DSS не открываются и в главном меню не работают.

Подходит любая версия MCM с глобальным `ModConfigMenu`, проверено на Mod Config Menu - Impure.
DSS отдельно ставить не нужно: он встроен в моды, которые его используют (например Fiend Folio).

Многие моды читают конфиг при `MC_POST_GAME_STARTED` и пишут его при выходе из забега. Поэтому:

- изменение сразу попадает в очередь `pendingConfig` в нашем сохранении, она переживает
  закрытие игры;
- опции MCM ещё и сразу получают `OnChange`, как в самом MCM;
- при старте забега, после всех модов, очередь записывается в моды. У DSS `store` вызывается
  только для изменённых кнопок, а его обработчик закрытия нужен лишь ради сохранения и видит
  пустой каталог: иначе он вызвал бы `store` всех кнопок, и Fiend Folio обнулил бы счётчики;
- из очереди удаляются только успешно применённые настройки. Если мод отсутствует,
  его обработчик выдаёт ошибку или DSS не смог сохранить данные, изменение остаётся
  для следующего старта забега;
- значения в меню могут быть устаревшими, пока мод не загрузил конфиг. Записываются только
  изменённые строки.

Страницы, которые мод добавляет только при старте забега (Reaction API, Reaction Pack), после
первого забега запоминаются в сохранении как данные (`cfgCache`) и дальше видны в меню сразу.
Подпись значения известна, только если оно уже встречалось в забеге, иначе справа показывается
число. Подразделы длиннее 30 строк не запоминаются (у Reaction API это списки всех предметов).

Ограничения: до первого забега такие страницы не видны.
Кнопки DSS с `func` серые, они рассчитаны на идущий забег. Всплывающие окна MCM, кроме
привязки клавиш, не поддержаны.

## Языки

Русский и английский, строки лежат в `bmm/lang.lua` (новый язык — копия таблицы `en`).
Пиксельный шрифт для мелкого текста без кириллицы, поэтому русские строки рисуются ванильным
шрифтом меню.

## Превью

Обложки Workshop показываются и в строках списка, и крупнее в карточке выбранного мода.
Они загружаются подготовительным скриптом через
[Steam Web API](https://partner.steamgames.com/doc/webapi/ISteamRemoteStorage#GetPublishedFileDetails)
и сохраняются как PNG в `resources/gfx/ui/bettermods/thumbs/workshop/<id>.png`.
ID читается из `metadata.xml`, затем из имени папки, поэтому переименование папки
не ломает связь с обложкой. На каждый мод создаётся один спрайт, используемый повторно.

Если в папке мода лежит `thumb.png`, превью берётся оттуда само: мод узнаёт путь к папке через
`XMLData` (`fulldirectory`) и загружает картинку любого размера. Работает только с настоящим PNG
(на Workshop `thumb.png` часто оказывается JPEG, такие игра не читает).

Приоритет: обложка Workshop → подготовленное превью папки → собственный `thumb.png`.
Чтобы подготовить картинки:

```bash
cd "mods/better-mods-menu"
python3 tools/make_thumbs.py              # thumb.png из папок модов
python3 tools/make_thumbs.py --download   # обновить обложки всех Workshop-модов (96x96)
```

Запускай после установки новых модов, затем перезапусти игру. Нужен Python 3 с Pillow.
Из исходного репозитория укажи `--mods-dir "/путь/к/Isaac/mods"`; `--output` позволяет
выбрать папку кеша. При недоступности Steam старые обложки сохраняются, скрипт сообщает
об ошибке. Внутри игры сетевых запросов нет; новые обложки подготавливаются этим скриптом.

## Файлы

- `main.lua` — ввод, маска, синхронизация курсора, профили
- `bmm/model.lua` — список модов, категории, зависимости, ванильный порядок
- `bmm/repsearch.lua` — зеркало поиска/отката REPENTOGON
- `bmm/ui.lua` — отрисовка
- `bmm/thumbs.lua` — выбор и кеширование спрайтов иконок
- `bmm/save.lua` — настройки, профили, снимок состояния при запуске
- `bmm/lang.lua` — переводы интерфейса
- `bmm/config.lua` — настройки из MCM и DSS, очередь записи
- `tools/build_gfx.py` — генерирует иконки и `.anm2`
- `tools/make_thumbs.py` — превью модов
- `tools/make_release.py` — чистая копия для Workshop

## Выпуск

```bash
python3 tools/make_release.py   # чистая копия в dist/better-mods-menu
```

В копию попадают только файлы из git, без `tests/`, генератора графики и чужих обложек
(их делает `make_thumbs.py` у каждого игрока сам). Эту папку и загружай через
`tools/ModUploader` игры; id Workshop берётся из `metadata.xml`.

## Изменения в 2.4

- Обложки модов в строках списка и в карточке; без обложек колонка не показывается.
- Галочки убраны: выключенный мод — бледное название и обложка. Новая шестерня у модов с настройками.
- Весь текст шрифтом меню игры, мелкий тоже.
- Звуки игры: курсор, вкл/выкл мода и галочек настроек, фильтры и значения влево/вправо.
- Пустые фильтры пропускаются; если в текущем фильтре не осталось модов, он сбрасывается на «все».
- Геймпад: Y сохраняет профиль, B отменяет ожидание клавиши; подсказки для геймпада.
- Очередь настроек больше не теряет изменения при ошибках, исправлены F2, повреждённые
  сохранения, совпадение Workshop ID и др. (см. «Проверки разработчика»).
- Карточка мода целиком помещается в узкое окно.

## Проверки разработчика

Из корня проекта:

```bash
lua tests/run.lua
python3 -m unittest discover -s tests -p 'test_*.py'
```

Lua-тесты используют настоящий код BMM и JSON-библиотеку Isaac, подменяя API игры
и отрисовку. По умолчанию `json.lua` ищется в стандартной Linux-установке Steam;
для другой установки задай `ISAAC_SCRIPTS=/путь/к/resources/scripts`. Нужен Lua 5.3+
и Python 3 с Pillow. Тесты не изменяют игровые сохранения и `disable.it`.

Проверка 2026-11-22: воспроизведены и исправлены потеря очереди настроек при ошибках,
выход за односторонние границы MCM, рассинхронизация поиска и переключений после F2,
неверный порядок ENTER + BACKSPACE, незакрытая панель после F2 и ошибка обновления
настроек вне защитного обработчика. Также исправлены перенос прокрутки описания на
другой мод, загрузка повреждённых полей/профилей сохранения, совпадение только начала
Workshop ID и имена файлов превью для Unicode-папок. Скрытые кнопки DSS теперь
учитывают `displayif`, возвращающий `nil`, а пустые списки вариантов нельзя редактировать.

Новые исправления проверены автоматическими тестами. Позже в тот же день версия
проверена в игре: иконки Workshop в строках и карточке, карточка целиком в окне, страница
настроек, лог без ошибок. У модов без обложки на месте иконки рисуется пустая рамка, чтобы
названия стояли в одну колонку. Геймпад после этих изменений повторно не проверялся.
