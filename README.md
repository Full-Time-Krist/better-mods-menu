# Better Mods Menu 2.1

Улучшенное ванильное меню модов для The Binding of Isaac: Repentance+. Нужен **REPENTOGON**.

Это не отдельное окно, а то же меню модов: та же бумага, курсор, записки «PRESS TAB» и
«PRESS ⟵ TO UNDO», нарисованные спрайтами самой игры. Поверх них добавлены нужные функции.

## Что умеет

- Лист и стена неподвижны, список плавно прокручивается под шапкой.
- Чекбоксы, метка категории (API / CONTENT / QOL / VISUAL), `+`/`-` у модов, которые
  изменятся после перезапуска, `⚠`, если включённому моду не хватает зависимости.
- Карточка мода: название, версия, Workshop ID, теги, превью, статус и описание.
- Зависимости определяются по описанию мода (ссылки на Workshop и названия рядом со словами
  «requires», «depends on»…). **D** включает все недостающие.
- Фильтры: все, вкл, выкл, закреплённые, API, контент, QoL, визуал, изменённые, сломанные.
- Сортировка: по имени, сначала включённые, по категории.
- Закреплённые моды всегда наверху.
- Профили: 4 слота, плюс «как при запуске игры» и «всё выключить».
- Поиск (CTRL) и откат (BACKSPACE) от REPENTOGON работают как раньше.

## Управление

| Клавиша | Действие |
|---|---|
| ↑ ↓, колесо мыши | выбор мода |
| PgUp / PgDn, Z / X, Home / End | листать |
| ← → или Q / E | фильтр |
| ENTER / SPACE | включить/выключить мод |
| S | сортировка |
| B | закрепить мод |
| D | включить недостающие зависимости |
| [ ] | прокрутить описание |
| P | профили (ENTER применить, S сохранить в слот, C очистить, SHIFT+1..4 быстро сохранить) |
| CTRL | поиск (печатать, ENTER закончить) |
| BACKSPACE | отменить все изменения с момента запуска игры |
| TAB | выключить/включить все моды (ванильная функция) |
| F2 | вернуть обычное ванильное меню (и обратно) |
| L | язык интерфейса: русский / English (по умолчанию — как в настройках игры) |
| ESC | выйти |

Геймпад: крестовина, LB/RB — фильтр, LT/RT — листать, кнопка MENUEX — профили. С геймпадом
мод не проверялся.

## Как это устроено

Lua не может сам включать моды. Поэтому мод перехватывает ввод меню (`MenuManager.SetInputMask`),
рисует свой список и ставит ванильный курсор (`ModsMenu.SetSelectedElement`) на выбранный мод.
Нажатие ENTER доходит до игры, и REPENTOGON переключает мод и пишет `disable.it` как обычно.
Профиль применяется так же: курсор сам переходит к каждому моду, который нужно изменить, и
на каждый нужно нажать ENTER.

`bmm/repsearch.lua` покадрово повторяет логику поиска и отката REPENTOGON
(`ModsMenuStuff.cpp`): клавиатуру он читает напрямую, и без этого порядок списка разошёлся бы.

Если в коде мода что-то упадёт, он снимает маску ввода и до конца сессии показывает ванильное
меню, так что застрять в меню нельзя. Ошибка пишется в `log.txt` с префиксом `[BetterModsMenu]`.

## Языки

Русский и английский, строки лежат в `bmm/lang.lua` (новый язык — копия таблицы `en`).
Пиксельный шрифт для мелкого текста без кириллицы, поэтому русские строки рисуются ванильным
шрифтом меню.

## Превью

Если в папке мода лежит `thumb.png`, превью берётся оттуда само: мод узнаёт путь к папке через
`XMLData` (`fulldirectory`) и загружает картинку любого размера. Работает только с настоящим PNG
(на Workshop `thumb.png` часто оказывается JPEG, такие игра не читает).

Для остальных модов превью можно подготовить заранее, они важнее `thumb.png`:

```bash
cd "mods/better-mods-menu"
python3 tools/make_thumbs.py              # thumb.png из папок модов
python3 tools/make_thumbs.py --download   # + обложки из Steam Workshop (96x96, рисуются в 2x)
```

Запускай после установки новых модов. Нужен Python 3 с Pillow.

## Файлы

- `main.lua` — ввод, маска, синхронизация курсора, профили
- `bmm/model.lua` — список модов, категории, зависимости, ванильный порядок
- `bmm/repsearch.lua` — зеркало поиска/отката REPENTOGON
- `bmm/ui.lua` — отрисовка
- `bmm/save.lua` — настройки, профили, снимок состояния при запуске
- `bmm/lang.lua` — переводы интерфейса
- `tools/build_gfx.py` — генерирует иконки и `.anm2`
- `tools/make_thumbs.py` — превью модов
